# Angular Lab

Laboratorio personal para practicar Angular - Personal laboratory to practice Angular.

Este proyecto fue generado usando [Angular CLI](https://github.com/angular/angular-cli) versión 21.0.2.

## Requisitos previos / Prerequisites

- Node.js (v18 o superior)
- npm (v10 o superior)
- Angular CLI (`npm install -g @angular/cli`)

## Instalación / Installation

```bash
# Clonar el repositorio
git clone https://github.com/juanjocl33/angular_lab.git
cd angular_lab

# Instalar dependencias
npm install
```

## Servidor de desarrollo / Development Server

Para iniciar un servidor de desarrollo local:

```bash
ng serve
```

Navega a `http://localhost:4200/`. La aplicación se recargará automáticamente al modificar los archivos fuente.

## Generación de código / Code Scaffolding

Angular CLI incluye herramientas de scaffolding. Para generar un nuevo componente:

```bash
ng generate component component-name
```

Para una lista completa de schematics disponibles:

```bash
ng generate --help
```

## Construcción / Build

Para construir el proyecto:

```bash
ng build
```

Los artefactos de construcción se almacenarán en el directorio `dist/`.

## Pruebas unitarias / Unit Tests

Para ejecutar las pruebas unitarias con [Vitest](https://vitest.dev/):

```bash
ng test
```
